# 方向 A「现代深色精致风」设计基准

> 阶段一范围：全局设计令牌 + 欢迎面板 + 会话页框架（Sider / 协议 Tabs / 桌面工具栏）。
> 本文档是后续向其余界面（新建连接模态、凭据模态、文件管理、设置等）推广时的基准。

参考基调：Warp / Raycast / Linear 的共性 —— 层次化深灰、1px 发丝边框、克制的点缀色、明确的排版层级、只回应操作的短动效。

## 1. Token 系统

### 色彩（深灰层叠，拒绝纯黑）

| Token | 值 | 用途 |
|---|---|---|
| `--ar-bg-base` | `#0E1116` | 应用底色（Layout body、桌面视口外围） |
| `--ar-bg-panel` | `#151A21` | 常驻面板（Sider、antd 容器色 colorBgContainer） |
| `--ar-bg-elevated` | `#1C222B` | 抬升层（卡片、hover 面、antd colorBgElevated） |
| `--ar-bg-active` | `#223142` | 选中态（活跃会话项；带蓝倾向，呼应品牌色） |
| `--ar-border` | `rgba(255,255,255,0.08)` | 常规发丝边框（antd colorBorder） |
| `--ar-border-subtle` | `rgba(255,255,255,0.05)` | 次级分隔（antd colorBorderSecondary） |
| `--ar-border-strong` | `rgba(255,255,255,0.14)` | hover / 聚焦边框 |
| `--ar-text` | `#E2E8F0` | 主文字 |
| `--ar-text-secondary` | `#97A3B4` | 次级文字（host、描述） |
| `--ar-text-tertiary` | `#5E6B7D` | 弱化文字（用户名、小节标题、提示） |
| `--ar-accent` | `#5B9BFF` | 品牌蓝：仅点缀（主按钮、聚焦环、链接、活跃指示） |
| `--ar-accent-hover` | `#74ACFF` | 品牌蓝 hover |
| `--ar-success` | `#4CC38A` | 低饱和绿（连接状态点） |
| `--ar-danger` | `#E56363` | 低饱和红（删除、断开） |

协议功能色（信息编码，非装饰）：

| 协议 | 色值 | 说明 |
|---|---|---|
| SSH | `#4CC38A` | 终端绿，低饱和（避开 acid-green 陈词：只作 3px 色签与小图标，不作大色块） |
| VNC | `#8B7CF6` | 桌面紫，与品牌蓝拉开 |
| 其他/未知 | `#8A95A5` | 中性灰 |

### 排版

- 正文栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`（无外部字体下载，CSP/离线友好）。
- 等宽栈：`ui-monospace, "JetBrains Mono", "SF Mono", SFMono-Regular, Menlo, Consolas, monospace` —— 只用于 host/IP、路径等技术数据（`.mono`）。
- Type scale：`12`（meta/标签）/ `13`（正文、列表）/ `14`（强调正文）/ `16`（小节标题）/ `20`（页面标题）/ `28`（欢迎页 wordmark）。
- 字重对比：400 正文 / 500 列表主信息 / 600 标题。小节标题不用 ALL-CAPS（skill 禁忌），用 12px 句首大写 + tertiary 色。

### 间距 / 圆角 / 阴影 / 动效

- 4pt 网格：4 / 8 / 12 / 16 / 20 / 24 / 32。
- 圆角分级：卡片/面板 10px，控件（按钮、输入、Select）6px，标签/kbd 4px。
- 阴影只做层级：`0 8px 24px rgba(0,0,0,0.4)` 用于 hover 抬升与浮层；平铺元素不堆阴影。
- 动效 120–180ms `ease`，只回应 hover / 展开 / 切换；无入场动画堆砌。

### antd ConfigProvider 映射

```
algorithm: darkAlgorithm + compactAlgorithm
token: colorPrimary/colorInfo=#5B9BFF, colorBgLayout=#0E1116,
       colorBgContainer=#151A21, colorBgElevated=#1C222B,
       colorBorder/colorBorderSecondary 见上, colorText 系列见上,
       borderRadius=6, fontSize=13, fontFamily/fontFamilyCode 见上
components: Tabs（去 editable-card 盒感）、Button、Input、Tag、Tooltip 微调
```

## 2. 布局概念

### 欢迎面板（工作台空态）

内容收拢成一条 max-width 720px 的中轴列，垂直方向上中部偏上但用 hero 输入区建立视觉重心，消灭死黑半屏。

```
┌────────────────────────────────────────────────────────┐
│                                                        │
│                   DeskMux  (28/600)                    │
│              输入目标地址，自动探测协议 (13, tertiary)    │
│                                                        │
│        ┌──────────────────────────────────────┐        │
│        │ ⌕  输入目标 IP 或主机名…        [扫描] │  hero  │
│        └──────────────────────────────────────┘  (48px,聚焦环)
│            ⏎ 直连或扫描新地址 · ⌘K 新建连接  (12, kbd)   │
│        [ B1 精确匹配横幅：Alert 重设计样式 ]              │
│                                                        │
│   已保存连接 · 3  ← 12px tertiary 小节标题（句首大写）     │
│   ┌─────────────────────┐ ┌─────────────────────┐      │
│   │▌●SSH  mac-studio    │ │▌●VNC  build-server… │      │
│   │  admin@192.168.50.44│ │  silk@100.110.128.32│ mono │
│   │                  ✎ 🗑│ │                  ✎ 🗑│ hover│
│   └─────────────────────┘ └─────────────────────┘      │
│        2 列网格卡片；▌= 3px 协议色签；hover 抬升+描边      │
└────────────────────────────────────────────────────────┘
```

- 对齐：中轴列居中，列内全部左对齐。
- 卡片信息层级：名称 14/500 主信息 → host 等宽 12 secondary → 用户名并入 `user@host` 前缀弱化；协议由色签+小字标签编码。
- 整卡单击直连；编辑/删除图标按钮 hover 显现。
- 空态是行动的邀请：无已保存时显示一句指向新建/扫描的引导，不留空白块。

### 会话页框架

```
┌──────────┬─────────────────────────────────────────────┐
│ ⌁ DeskMux│ 桌面  终端  文件管理          (轻量下划线 Tabs)│
│ ┌────────┐ ├─────────────────────────────────────────────┤
│ │+ 新建连接│ │                                             │
│ └────────┘ │  ┌─桌面工具栏─────────────────────────────┐  │
│ 活跃会话     │  │ 缩放▾ 光标⚇ ⚙ │ 👁 ⌨ ⛶ │ 名称   断开 │  │
│ ┌────────┐ │  └──────────────────────────────────────────┘  │
│ │● 名称  ×│ │  ┌─桌面视口───────────────────────────────┐  │
│ │  host   │ │  │                                        │  │
│ └────────┘ │  │                                        │  │
│ 已保存连接   │  │                                        │  │
│ ┌────────┐ │  │                                        │  │
│ │▌名称  ✎│ │  │                                        │  │
│ │  host   │ │  │                                        │  │
│ └────────┘ │  └──────────────────────────────────────────┘  │
│ [断开连接]  │                                             │
└──────────┴─────────────────────────────────────────────┘
 232px Sider
```

- Sider：panel 底色 + 右侧发丝边；小节标题 12px tertiary；会话项 = 卡片（状态点 + 名称 13/500 + host 等宽 12 省略号不断词）；活跃项 elevated-active 底 + 左侧 2px 品牌蓝指示条；关闭 × / 编辑 ✎ hover 显现。
- Tabs：覆盖 antd editable-card —— 去盒、去底色，活跃页签用 2px 底部品牌蓝指示，非活跃 tertiary 文字；关闭 × 保留。
- 桌面工具栏：控件按功能分组，组间 1px 竖分隔线：`缩放 / 光标 / 显示设置` | `只读 / 发送按键 / 全屏`，右侧 `desktopName（等宽弱化）+ 断开`；图标按钮统一 28px 高、hover elevated 底。

## 3. 独特性自审（对照 skill 的"通用 AI 默认审美"清单）

1. **不是"近黑底 + 单一 acid-green/朱红点缀"**：底色是 #0E1116 深灰蓝，三层灰层叠；品牌色是精调蓝，绿色只出现在 SSH 协议编码与状态点这类功能语义里，且低饱和。
2. **不是 SaaS 卡片套件**：卡片不是"内容切进一律同圆角同灰阴影的盒子"——圆角分级（10/6/4），平铺卡片无阴影，只有 hover 才抬升；卡片左侧的 3px 协议色签是连接管理器领域的本地语言（1Remote / Royal TS 的协议标识传统），不是装饰。
3. **不堆砌模板 chrome**：无 ALL-CAPS eyebrow 标签、无 'A · B · C' 中点串、无 '→' 按钮后缀、无编号标记。小节标题用句首大写 12px。
4. **等宽字体的使用有语义**：只给 host/IP/路径等技术数据，不当"小数据标签"的通用风格装饰。
5. **动效纪律**：全部 ≤180ms 且只回应用户操作；无入场 fade-and-slide-up。
6. **品牌感的落点**：克制的蓝 + 深灰蓝底色 + 协议色签系统，三者构成可识别的 DeskMux 视觉签名；大胆只花在欢迎页 hero 输入区一处（48px、聚焦环、kbd 提示），其余界面保持安静。

结论：方案围绕"远程连接管理器"这一主题的真实语汇（协议色、等宽主机地址、状态点）构建，不落入通用默认审美，可以进入实现。

## 4. 修订记录（v2，"出门前摘一件配饰"批判）

1. **活跃会话不再用蓝色左指示条**：此前活跃卡同时有 2px 品牌蓝指示条 + 绿状态点，两个元素表达同一状态。保留绿点（它编码"连接存活"这一信息），活跃态只由 `--ar-bg-active` 抬升底色 + 发丝边框表达。
2. **"已连接"置灰态（新表达方式，推广时沿用）**：Sider 已保存列表中，与某活跃会话同身份（`savedId` 匹配，同 host 其他身份不受影响）的卡整卡 `opacity: 0.55`，名称右侧加 11px 描边徽标（`.connected-badge`）；点击该卡切换（`setActiveSession`）而非再开重复会话。欢迎面板空态不可能有活跃会话，不适用此态。
3. **提示行去除 "·" 中点分隔符**（模板腔）：两条 hint 拆成独立 span，`gap: 16px` 并排。
4. **欢迎页视觉重心 42%**：容器 flex 纵向居中 + `padding-bottom: max(40px, 16vh)` 把整块内容上移（用 padding 而非 transform，设备列表变长时滚动不受影响）；删去品牌区固定 `margin-top` 堆叠。
